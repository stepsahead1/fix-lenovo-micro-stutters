# How to fix Sluggish Lenovo laptop. 
- Problem with computers featuring two GPU, Intel and Nvidia

## Instructions to get rid of micro-stutters on Lenovo 83L0:
- Uninstall the installed application MEMCFT from Ms Windows
- Switch from Display scaling to GPU scaling
- Disable variable frequency in intel graphics software
- Switch from Auto to Optimus in Nvidia settings
- Uninstall Lenovo smart connect
